FantaChat - snapshot del codice

Questa cartella e una fotografia del progetto preparata per la revisione del codice.

Per leggere il progetto:
1. Aprire la cartella con Visual Studio Code.
2. Installare le dipendenze con: npm install
3. Per avviare l'app serve un file .env.local creato separatamente.
4. Avviare con: npm run dev

Per sicurezza non sono stati inclusi:
- credenziali e file .env;
- node_modules e .next;
- repository Git e cartelle temporanee;
- chiavi Android, certificati e file APK/AAB.

Le modifiche fatte in questa copia restano locali e non modificano il progetto originale.
